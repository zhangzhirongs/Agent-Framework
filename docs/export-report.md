# 验证与打包

本框架基于公开 SDK 实现基础对话、标准技能和 MCP 工具调用。

## 功能范围

- OpenAI 兼容模型的流式对话和通用工具调用循环。
- 标准 `SKILL.md` 目录、导入、正文与资源读取、按需加载。
- 标准 `mcpServers`、stdio / Streamable HTTP / SSE、工具白名单。
- 可选联网搜索、登录、基础附件读取与预览、文本文件输出。
- 可自行填写的配置模板和中文开发文档。

## 公共资源

图标来自 Lucide，静态封面为 NASA 公共影像，来源和许可见资源文档。界面采用 BeUI 官方公开 Registry 组件，保留 MIT 许可及组件交互动效。技能目录附带通用笔记示例 `example-note`。

## 验证方式

- 后端测试使用本地模拟模型协议，验证对话历史、流式事件、技能实际加载、文本文件输出、鉴权与数据隔离、错误配置处理及取消状态。
- MCP 测试实际启动本包的 stdio 示例服务，并由智能体工具调用完成 `ping`；测试不控制浏览器。
- 三种联网搜索适配器均使用模拟 HTTP 请求验证配置传递。
- 前端请求测试与 TypeScript / Vite 构建检查。
- 分发脚本按源码白名单打包，排除 `.env`、数据库、依赖、构建产物和缓存，并检查常见密钥、私人路径、私网地址与非空供应商配置。打包后附源码哈希清单。

验证未调用真实供应商模型，也未执行浏览器自动化验收。真实供应商兼容性、外部技能依赖与第三方 MCP 可用性需要使用自己的配置验证。

验证结果：22 项后端测试、2 项前端请求测试通过，Ruff 检查和 TypeScript / Vite 构建通过；源码分发检查通过。验证使用独立安装的依赖。

## 打包检查

在项目根目录运行：

```sh
uv run python scripts/verify_distribution.py
uv run python scripts/package_release.py ../agent-framework-release.zip
```

第二个命令要求输出文件不存在。ZIP 只包含通过检查的源码、文档、公共静态素材及许可证，不包含本机运行产生的数据。

扫描是自动检查的一层，不能证明所有形式的私密信息都能被识别。后续开发者添加新文件、供应商配置或第三方资源后，仍需审阅交付范围与授权。

## 已知边界

服务使用单进程运行，扩展方式见运行文档。Word 采用文字预览；扫描 PDF 不含 OCR。技能内脚本可随目录保存，但不会仅因导入而执行；需要额外执行能力时接入经过审核的 MCP，并安装相应依赖。
